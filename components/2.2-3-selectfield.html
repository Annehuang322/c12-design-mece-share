这个组件是干什么的

当多个业务入口重复使用 SelectField 的视觉、状态或交互规则时， 就把它抽出来做成统一组件。业务数据怎么转换，仍放在具体业务页面里处理。

组件类型：表单录入类。涉及位置：UnifiedSelect, 报告入口 category, Return category, wizard eluent

现在的问题是什么

打开 报告入口 category；UnifiedSelect 不可点击=true。

建议怎么改

展示 placeholder、选中、打开、不可点击、错误状态、long option。

合并；options 留业务层。

产品/设计需要判断什么

category 排序和文案保留业务；宽度是否随容器。
