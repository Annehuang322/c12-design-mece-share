这个组件是干什么的

当多个业务入口重复使用 RuntimeLogLine 的视觉、状态或交互规则时， 就把它抽出来做成统一组件。业务数据怎么转换，仍放在具体业务页面里处理。

组件类型：状态日志类。涉及位置：runtime-log-console、step-execution-log-弹窗、experiment-history-view、experiment-progress-kanban

现在的问题是什么

打开 Runtime Log、Step Work Log、History audit、Kanban inline；切模式并筛 warn，记录日志条数、颜色、缩进和 raw JSON 展示。

建议怎么改

日志条数、颜色、缩进、raw JSON 换行一致；compact/detailed/geek 作为展示模式回归。

抽纯展示行，统一 routine/warn/error + compact/detailed/geek。

产品/设计需要判断什么

routine 无 badge；warn/error 有 badge；inline 字体更小。
